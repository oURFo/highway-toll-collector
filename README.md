# 🛣️ 國道收費員 Highway Toll Collector

扮演民國 88 年春節連假的國道收費員：在 **3 分鐘** 內目視辨別車種、核對回數票、心算找零、控制柵欄，還要抓闖關車、禮讓救護車。系統 **零防呆**——畫面只有票價列可查，收對收錯、要不要退票、何時開閘全靠你自己判斷。

沒經歷過人工收費時代？標題畫面的 **📖 新手教學** 會暫停計時，用 6 台示範車一步步帶你操作：收回數票、退錯票、識破假票、現金找零、禮讓救護車、拍照舉發闖關車。

▶ **線上遊玩**：https://ourfo.github.io/highway-toll-collector/

## 玩法

| 車種 | 費率 | 回數票 |
|---|---|---|
| 🚗 小型車 | 40 | 藍票 |
| 🚌 大型車（遊覽車／貨車） | 50 | 綠票 |
| 🚛 聯結車（貨櫃拖車） | 65 | 橘票 |
| 🚑 救護／消防／警車 | 0 | 免收，直接開閘 |

- 每 7 秒來一台車，停靠後駕駛耐心 20 秒，歸零會撞斷柵欄闖關（維修費 $300、客訴 +1）。
- **【票務與閘門】**：檢查票色與假票（字跡模糊、缺角、過期、沒有「高公局驗訖」章）→ 收下或退回；確認收齊後開閘放行。
- **【收銀找零】**：心算「付款 − 費率」，點 500／100／50／10／5 元後交付找零。
- 闖關車衝過時，3 秒內按【緊急拍照舉發】。

## 評級

- **S** 國道傳說神手：0 客訴、0 損失、0 失職、通行 ≥ 18 輛
- **A** 資深站務員／**B** 過勞約聘員／**C** 賠錢扣薪族
- **F** 記過解雇：攔救護車 ≥ 1、客訴 ≥ 5、漏抓闖關＋撞斷柵欄 ≥ 3、營業損失 > $500 任一項，並登上「國道日報」頭條。

## 技術

- 單頁 HTML5 + Vanilla JS + Tailwind CSS（CDN），直式滿版、禁止縮放
- 車輛、回數票、鈔票硬幣全部以 SVG／CSS 繪製，無外部圖檔
- 音效全部以 Web Audio API 即時合成（引擎、喇叭、撕票、硬幣、柵欄、救護車鳴笛、快門、撞擊）
- GitHub Pages 靜態部署
